# rhizome

The shared node API and per-app object models for the preset.nz desktop suite. A network of nodes with no fixed centre.

**Status: planning.** Nothing is scaffolded yet. The first slice is `rhizome-core` (Rust); `rhizome-wasm` and the generated TypeScript package wait for a second consumer.

## Design docs

`guidance/` holds **copies** of the planning docs so the work can continue away from the main machine. The canonical versions live in the private guidance repo (`design/node-api.md`, `handovers/shard/handover-node-api.md`). Edit there, then recopy. Relative links inside the copies won't resolve.
